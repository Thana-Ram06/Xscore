PHASE 1: REAL ENGAGEMENT DATA
----------------------------------------

Update the /api/analyze route:

- Fetch recent tweets (last 5–10) using the same RapidAPI Twitter/X API
- Extract:
  - likes
  - replies

- Calculate:
  avgLikes = totalLikes / numberOfTweets
  avgReplies = totalReplies / numberOfTweets

- Compute engagement rate:
  engagementRate = (avgLikes + avgReplies) / followers * 100

- Replace previous random engagement with real calculated value

- Keep fallback:
  If tweets are not available → use safe default value

PHASE 2: SMART SCORING ENGINE (IMPROVED)
----------------------------------------

Update scoring logic:

- Engagement score (highest weight)
- Follower quality:
  - Penalize if followers high but engagement low
- Authority score:
  - followers / following ratio
- Activity score:
  - based on tweet count

Combine:
score = weighted sum → normalize to 0–1000

Return detailed breakdown:
{
  score,
  engagementRate,
  breakdown: {
    engagement,
    followerQuality,
    authority,
    activity
  }
}
