Build a modern AI-powered web app called "XScore" using Next.js 16 App Router, TypeScript, and Tailwind CSS.

The app analyzes X (Twitter) usernames and generates an influence score with analytics.

CORE FEATURES:
- Input field to enter X username
- Analyze button
- Fetch mock or API-based Twitter data (followers, following, tweets, engagement)
- Calculate score based on:
  score = (followers × engagement rate) / 100
- Display:
  - Score (0–1000)
  - Followers count
  - Engagement rate
  - Growth indicator
- Store previous searches in Firebase Firestore

UI/UX REQUIREMENTS:
- Premium SaaS UI inspired by tpot.cc and modern AI tools
- Centered layout
- Minimal, clean, high-end design
- Large hero typography
- Soft rounded cards
- No heavy shadows
- Subtle borders
- Smooth hover animations
- Dark mode (default) + light mode toggle

FONTS:

- Use "Inter" for body text

HOMEPAGE:
